# Scrollshield 🧠

**Take back control of your browsing experience.**

Scrollshield is a Chrome extension designed to reduce digital distractions by hiding selected website elements associated with endless scrolling, algorithmic feeds, and other attention-grabbing features.

The goal is simple: help people use the internet more intentionally without having to give up the websites they enjoy.

> **Project status:** In development 🚧

## ✨ Features

- **Feed Blocking:** Hide selected social media feed elements to reduce mindless scrolling.
- **Customizable Distractions:**  Choose which website elements you want to hide.
- **Multi-Website Support:**  Expand beyond social media to other distracting platforms.
- **Lightweight Design:** Focus on reducing distractions without unnecessarily complicating the browsing experience.
- **Word Blocker:** A word blocker has been added that allows users to avoid sites that contain said word

## 💡 Why Scrollshield?

Many websites are designed to keep users engaged for as long as possible through endless feeds, recommendations, and other attention-grabbing features.

Scrollshield explores a different approach: **make the websites you use less distracting, rather than relying entirely on willpower to avoid distractions.**

Instead of blocking an entire website, the goal is to let users keep the parts they find useful while removing the features they find distracting.

A new feature has been added where you can now block specific words, and if the words are on the preceding web page, a warning message will appear, asking if the user would like to continue.

## 🚀 Installation

### Option 1: Install from the Chrome Web Store

_Coming soon, if the extension is published._

### Option 2: Install from GitHub

1. Download or clone this repository.
2. If you downloaded a ZIP file, extract it to a folder on your computer.
3. Open Google Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the project folder containing `manifest.json`.

Undistract should now appear in your installed extensions.

**Note:** The extension must be loaded from the folder containing its `manifest.json` file. You may need to reload the extension after making code changes.

## 🧪 Development

To contribute to development:

1. Clone the repository.
2. Open the project folder in your code editor.
3. Navigate to `chrome://extensions` in Chrome.
4. Enable Developer mode and load the project using **Load unpacked**.
5. Make your changes and click the extension's reload button in Chrome.
6. Refresh the website you're testing to see your changes.

Use Chrome DevTools to inspect website elements and debug the extension's content scripts.

## 🔒 Privacy

Undistract is intended to help users manage distractions locally in their browser.

This browser extension collects no personal information about you, it only removes distracting feeds.
